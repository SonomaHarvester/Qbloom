# {{NAME}}

Qt Quick 6 sample generated by qbloom. C++ supplies the greeting and counter through a QObject with notification signals.

See `QBLOOM_PROJECT_GUIDE.md` for the manifest, commands, and smoke test contract.

Run `qbloom` commands from the directory containing `qbloom.toml`. When this sample was added to an existing project, that directory is the parent of `qbloom_quick`.

## Commands

```sh
qbloom doctor
qbloom build
qbloom run
qbloom test --headless
qbloom clean
```

Requires Qt 6.8 or newer with Quick, Qml and QuickControls2, CMake and a C++17 compiler. `qbloom test --headless` uses Qt's offscreen platform plugin; a working graphical environment or plugin is required.
