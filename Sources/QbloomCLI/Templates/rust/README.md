# {{NAME}}

Qt Quick application with a Rust `QObject` backend generated by qbloom.

See `QBLOOM_PROJECT_GUIDE.md` for the manifest, commands, and smoke test contract. Run qbloom from the directory containing `qbloom.toml` (the original project root for `add`).

## Requirements

- Rust 1.85 or newer and Cargo
- Qt 6.8 or newer development files, including Quick, QML, and Quick Controls
- C++ compiler and `qmake6`

Run `qbloom doctor`, `qbloom build`, `qbloom run`, and `qbloom test --headless`.
Cargo is the authoritative build tool. The top-level CMake target invokes `cargo build --locked` for integration with CMake workflows. Dependency resolution occurs when building, not while scaffolding.
